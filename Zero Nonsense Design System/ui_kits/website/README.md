# Zero Nonsense — Website UI Kit

Premium "purely transparent" marketing site: frosted-glass chrome floated over full-bleed cloudy sky, per the user's direction. No existing website source existed — this is an original composition strictly from the brand guidelines (palette, Averia Serif Libre + Geist Mono, stamp motifs, packaging copy).

`index.html` — homepage: glass nav, sky hero with hand-lettered wordmark, product range switcher (Adult / Kids / OBEIT), transparency promise section with rubber stamp, add-to-bag dialog + toast, airmail footer. Interactive: tabs, dialog, toast, hovers.
